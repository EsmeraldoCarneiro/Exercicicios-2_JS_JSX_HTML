## 📚 Laboratório de Desenvolvimento: Da Lógica ao React
Este repositório reúne uma sequência de exercícios práticos focados na evolução das habilidades de front-end. O objetivo é demonstrar a fluência na lógica de programação e a transição da manipulação direta do DOM para o desenvolvimento declarativo com React.

🛠️ Estrutura de Aprendizado
Lógica de Programação & JS Puro: Implementação de algoritmos para cálculos matemáticos (médias, potências, somas) utilizando JavaScript Moderno (ES6+). Foco em validação de entradas, tratamento de erros e manipulação de tipos de dados.

Estruturação com HTML: Criação de interfaces básicas e tabelas, garantindo a semântica correta antes da estilização e do dinamismo.

Transição para React: Exercícios que exploram o React.createElement para entender como a biblioteca gerencia elementos em memória antes de renderizá-los.

Modernização com JSX: Aplicação de JSX e Babel para criar interfaces de forma declarativa, utilizando as APIs mais recentes do React 18 (createRoot).

💡 <i>Destaques Técnicos<br></i>
+ ***Sintaxe Moderna***: Uso de Template Literals, operadores de exponenciação (**) e Arrow Functions.

+ ***Renderização***: Migração do document.write e innerHTML para o ecossistema do Virtual DOM.

+ ***Validação Dinâmica***: Implementação de funções de captura de dados com loops de validação (while e isNaN).</i>

### Por que isso é relevante no meu perfil?
Como Analista e Desenvolvedor de Sistemas, acredito que a base sólida é o que permite construir aplicações escaláveis. Estes exercícios documentam minha capacidade de entender o "porquê" das coisas, e não apenas o "como".
